# Presentation Speaker Notes (target: 15 minutes)

Suggested division: Anderson opens and presents product/requirements; Azaevion presents architecture/testing/deployment. Adjust to match who actually completed each part.

1. **Title and team (1 min):** Introduce Student Success Hub and both team members.
2. **Opportunity (1.5 min):** Explain the student organization problem and intended users.
3. **Product vision (1 min):** Read the product vision and explain the value.
4. **Features (1.5 min):** Show registration, dashboard, assignment management, goals, and progress summary.
5. **User stories (1.5 min):** Discuss three examples: add an assignment, prioritize work, track an academic goal.
6. **Scenarios (1.5 min):** Walk through registering, adding a task, and completing a goal.
7. **Architecture (2 min):** Explain browser → Flask → SQLite and show the diagram.
8. **Live demo (2 min):** Register/sign in, add an assignment, mark it complete, create and complete a goal.
9. **Testing and engineering process (1 min):** Show actual test output, GitHub commit history, and Docker build evidence.
10. **Contributions and lessons (1 min):** Explain real division of work and lessons learned.
11. **Conclusion (30 sec):** Restate the value and show the verified public URL.

Demo preparation:
- Use a dedicated demonstration account with non-sensitive sample data.
- Confirm the public deployment is working before presenting.
- Keep a local copy ready in case Wi-Fi or the hosted service fails.
- Never display passwords, tokens, or private user data.
